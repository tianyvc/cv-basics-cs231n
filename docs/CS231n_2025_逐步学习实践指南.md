# CS231n 2025：从第一步到独立项目的学习实践指南

更新：2026-10-20。本文将原导览的第四节“学习顺序”和第七节“掌握标准”展开成可逐项执行的任务。路径适用于本仓库的 **2025 年作业模板**，不要求你先下载全部数据，也不提供完整作业答案。

## 1. 使用方式：一次只推进一个可验收的任务

先读 [仓库导览](CS231n_2025_仓库导览与学习路线.md) 了解资料位置，再按本页编号前进。每一步都包含材料、行动和通过条件。**完成阅读不等于通过：需要留下推导、代码结果或口头解释的证据。** 卡在某一步时，先做其小规模验证，再增加数据量或训练时长。

文中的路径统一相对仓库根目录；A1、A2、A3 分别是：

| 简称 | 实际作业根目录 |
|---|---|
| A1 | `assignments/assignment1/assignment1/` |
| A2 | `assignments/assignment2/assignment2/` |
| A3 | `assignments/assignment3/assignment3/` |

例如“A1 `cs231n/layers.py`”指第一份作业内的文件，不能改成第二份的同名文件。Notebook 是任务与检查的入口，`.py` 是主要实现入口，具体必做函数和阈值以 Notebook 当前要求为准。

材料优先级：**当前讲义与题目 → 对应笔记 → 检查与实验 → 原论文 → 可选拓展**。正文中的独立小练习、实验表格和口试均为自学建议，不是新增官方作业要求。已完成同等任务可以直接提供证据，通过后跳过重复阅读。

### 1.2 每次学习的固定流程

一次以约 2–3 小时为宜，任务难时拆成数次，不要为了赶“第几天”跳过验收。

1. **10 分钟回忆**：不看资料写出上次的核心公式、形状或算法步骤。
2. **30–45 分钟阅读**：只查本任务指定材料，先提出一个待解决问题。
3. **60–90 分钟推导或实现**：先用极小输入，再执行 Notebook 检查；记录首次失败的原因。
4. **20–30 分钟实验与解释**：保存图、配置、数值；写清哪些结果能支持结论。
5. **5 分钟收尾**：勾选已完成内容，留下阻塞原因和下一项具体行动。

记录可以用下面的模板，每次复制一份：

```markdown
## 日期 / 任务编号 / 实际用时
- 本次问题：
- 阅读文件与段落：
- 修改文件及函数：
- 输入形状 / 输出形状：
- 检查结果（误差、准确率或现象）：
- 配置（划分、随机种子、模型、学习率、训练轮数）：
- 错误与修正：
- 我的解释 / 仍不确定的地方：
- 下一步：
```

不要把题目给的“应该输出多少”填成自己的实验结果。没有数据/GPU时，把任务标记为“推导通过、完整实验待做”，后续补齐后才能算实验通过。

### 1.3 三种通过状态

| 状态 | 证据 | 可以推进到哪里 |
|---|---|---|
| 概念通过 | 能闭卷解释、推导并给出形状 | 继续读后续相关概念 |
| 实现通过 | 小张量、数值检查、边界情况符合预期 | 进入训练实验 |
| 实验通过 | 完整题内实验、曲线、问答、复现记录 | 将对应作业勾为完成 |

不把 CPU 算力不足误判成不会；也不把只看过代码误判成已经掌握。

### 02｜补 NumPy：能在运行前说出形状

**打开**：[NumPy 教程](../readings/notes/python-numpy-tutorial.md)、[交互练习](../readings/notes/python-colab.ipynb)。不熟悉单元执行再看 [Jupyter 教程](../readings/notes/jupyter-notebook-tutorial.ipynb)。

**依次行动**：

1. 练习数组创建、索引、切片、布尔掩码、`reshape`、转置、`sum/mean` 的 `axis` 和 `keepdims`。
2. 取 `X.shape=(4,3)`、`W.shape=(3,2)`、`b.shape=(2,)`，在纸上预测 `X@W+b`、`X.sum(axis=0)`、`X[:,None,:]` 的形状，再执行核对。
3. 为 `(4,3)` 和 `(5,3)` 两组向量构造 `(4,5,3)` 的差，再沿特征轴归约为 `(4,5)` 距离；说明广播为什么成立。
4. 用循环与向量化分别实现一个简单归约，检查结果一致，再比较运行时间。输入很小时不期待向量化必然显著更快。
5. 故意让两个不可广播形状相加，读懂报错；观察切片修改对原数组的影响，理解何时需要 `.copy()`。

**通过条件**：闭卷写对上述形状；能区分元素乘与矩阵乘；不靠不断 `reshape` 试错让代码勉强运行。

**产出**：一页“形状与广播速查”，保留至少一个自己修复的维度错误。

### 03｜数学诊断：只补后续真正会用到的部分

**打开**：[求导讲义](../readings/handouts/derivatives.pdf)、[线性反向传播](../readings/handouts/linear-backprop.pdf)。

**依次行动**：

1. 线性代数：解释向量点积、矩阵乘、转置、范数；为每一步写维度。
2. 微积分：手推一元复合函数，再对一个有两条分支汇入损失的标量图求梯度，注意贡献要相加。
3. 概率：写出均值、方差、条件概率、对数似然；解释高斯噪声、采样与期望的区别。
4. 用中心差分 `(f(x+h)-f(x-h))/(2h)` 检查一个简单可导函数；试几个 `h`，观察过大和过小时的误差。

**通过条件**：能说清“对一个矩阵参数求损失梯度”仍得到相同形状的矩阵；能解释链式法则、梯度与更新方向。ELBO 和扩散概率推导留到第 23–24 步，不必现在全部补完。

## 4. A1 路径：从像素分类走到手写深度网络

### 05｜完成 kNN：先正确，再向量化

**入口**：[A1 knn](../assignments/assignment1/assignment1/knn.ipynb)；修改 A1 `cs231n/classifiers/k_nearest_neighbor.py`。

**依次行动**：

1. 在纸上对两张微型图像算欧氏距离，说明像素距离容易受哪些变化影响。
2. 按 Notebook 顺序实现双循环、单循环、无循环距离；同一小输入逐项比较，而不只比较最终准确率。
3. 无循环实现时推导平方距离展开式，检查输出是测试数×训练数；处理浮点舍入带来的微小负值。
4. 实现最近邻投票，理解相同票数时的规则；在小输入上手工核对。
5. 按题目做交叉验证，保存 k 对验证效果的图和选择理由；测试集不参与选 k。

**知识要点**：训练保存数据、预测查邻居；k 太小/太大影响偏差与方差；向量化提高计算效率但不会消除距离矩阵的存储开销。

**通过条件**：三种距离计算一致；能推导表达式并估算矩阵所需空间；完成 Notebook 问答与交叉验证。

### 06｜完成 Softmax：把概率、损失和梯度连起来

**打开**：第 2–3 讲；[线性分类](../readings/notes/linear-classify.md)、[优化](../readings/notes/optimization-1.md)。**入口**：[A1 softmax](../assignments/assignment1/assignment1/softmax.ipynb)；`classifiers/softmax.py`、`linear_classifier.py`。

**依次行动**：

1. 给出 `X(N,D) → scores(N,C) → probabilities(N,C) → scalar loss` 的形状链。
2. 解释为何减去每行最大分数不改变 Softmax；对大正数输入检查是否仍有限。
3. 自己推交叉熵对 logits 的梯度，再沿线性层回到 W；写清平均损失和正则项的系数。
4. 先实现 naive，再向量化；比较损失和梯度，用 Notebook 有限差分检查。
5. 阅读 SGD 训练循环，确认采样、算 loss/grads、更新参数的先后关系。
6. 做小范围学习率/正则化搜索，只依据验证表现选择；保存曲线和权重可视化。

**通过条件**：解释初始近均匀预测时损失为何约为 `log(C)`（小初始化和较小正则时）；通过题内检查；能解释线性模型的表达局限。SVM 笔记用于对照，不必另找 2025 不存在的 `svm.ipynb`。

### 07｜反向传播：从纸上计算图到基础层

**打开**：第 4 讲；[反向传播笔记](../readings/notes/optimization-2.md)、两份求导讲义、`slides/2025/section_2.pdf` 与 `section_2_backprop.ipynb`。**入口**：[A1 two_layer_net](../assignments/assignment1/assignment1/two_layer_net.ipynb)；`layers.py`、`layer_utils.py`。

**依次行动**：

1. 画 `X → affine → ReLU → affine → loss`，标每个中间量形状。
2. 先实现 affine 前向，再从上游 `dout` 推输入、权重和偏置梯度；说明 batch 维为何对偏置求和。
3. 实现 ReLU 前/反向，解释为何 cache 要保留特定信息；对恰好为 0 的点讨论不可导约定。
4. 按 Notebook 检查每层，再检查组合的 affine-ReLU；使用小输入、较高精度，不直接上完整训练。
5. 对一个参数元素手动执行中心差分，把“数值梯度”和“解析梯度”在日志中并排记录。

**通过条件**：每一梯度形状与参数/输入匹配，题内误差符合要求；能解释分支梯度累加、广播反向时的归约。此时不要把 A1 中留给后续主题的所有 TODO 都当本任务范围。

## 5. A2 前半路径：训练技巧、CNN 与 PyTorch

### 12｜Dropout：训练与推理行为必须一致地定义

**入口**：[A2 Dropout](../assignments/assignment2/assignment2/Dropout.ipynb)；`layers.py`。

**依次行动**：

3. 选择一种表示画数据到损失的路径，说明监督来自哪里、如何评价几何或图像质量。

**产出/验收**：表示比较表、一个方法的数据流图；不能仅因渲染图好看就断言几何正确。

### 30｜机器人：从“识别”走向“采取行动”

**打开**：第 17 讲。

1. 写 observation、action、state、reward、policy 的含义，区分监督标签与环境反馈。
2. 比较行为克隆、强化学习、模型学习；解释离线数据与在线交互的不同代价。
3. 列出分布偏移、错误累积、sim-to-real 和真实环境评价问题。

**产出/验收**：用一个抓取任务解释数据如何收集、策略怎样训练、成功率怎样计算；不要求为了课程买硬件或下载仿真资产。

### 31｜Human-Centered AI 与阶段复习

**打开**：2024 `lecture_18.pdf` 作为补充；2025 第 18 讲无公开 slides。结合自己的项目，使用 `slides/2025/section_6.pdf` 复习基础。

1. 为自己的数据列受益人、可能受损的人、标签偏差与分布缺口；写出可以观察的失败条件。
2. 说明哪些评价还不足以支持真实使用，例如平均准确率掩盖少数群体错误。
3. 用期中复习 slides 提问，闭卷作答后再查资料；不将 slides 当作已经公开的官方完整试卷。

**产出/验收**：一页项目适用边界与误用分析、一份错题表。能清楚标出 18 讲中自己只学了概念、哪些做了实现、哪些做了完整实验。

## 10. 独立项目：把知识组织成有证据的结论

### 32｜固定一个可回答的问题与评价协议

从第 15 步 proposal 继续。优先考虑小规模分类与迁移/自监督特征比较，或使用自己可合法获取的小数据集。选题应涉及视觉数据。

1. 写单句问题，例如“在固定标签预算下，冻结的表征 A 是否优于随机特征基线？”明确这不等同于比较完整端到端系统。
2. 固定划分、样本量、预处理、主指标与预算；类别不平衡时同时看 macro-F1/每类指标。
3. 预先列出两项消融及预期证据，检查数据和算力是否够用。
4. 按官方项目说明整理 proposal，不为读全部往年项目延迟 baseline。

**验收**：其他人仅看一段描述，就知道你比较了什么、怎样判断成功。

### 33｜跑通 baseline 并交付 milestone

1. 固定数据版本、随机种子、配置和环境，训练一个最小 baseline；先检查小样本能学会。
2. 保存训练/验证曲线、模型选择规则、错误样例与资源开销。
3. 留一组未用于反复选择超参的最终测试；检查分组/时序数据泄漏。
4. 写 2–3 页 milestone：问题、方法、初步结果、失败和下一步。

**验收**：baseline 可从清晰命令或 Notebook 顺序复现；结果缺失时如实记录，不只写“预计可提升”。

### 34｜做消融，解释失败，限制结论

1. 一次只改变一个研究因素；确有多个改变则拆成多个配置。
2. 在预算允许时重复随机种子，说明均值/波动和重复次数；只有一次运行就坦诚说明。
3. 检查数据质量、类别混淆、置信度与失败模式，挑代表性成功与失败样例。
4. 用表格并排记录参数量、可训练参数、数据量、指标、时间及条件，避免比较规则不一致。
5. 对负结果给出证据与可能原因，区分已验证的原因和未验证的猜测。

**验收**：每个主要结论都能指出对应实验；不把相关性当因果，也不靠挑选样例支撑总体提升。

### 35｜完成报告与复现说明

按官方规范写 6–8 页报告，引用代码、论文和数据：Introduction → Related Work → Data → Methods → Experiments → Conclusion；可以按研究问题调整组织。

1. 报告写清问题、对照、主要结果和局限，方法与实验互相对应。
2. 提供安装、数据获取、训练/评价顺序、配置、预计资源和结果位置。
3. 新会话按说明运行可负担的检查；大型运行写清未复跑的原因和已有证据。
4. 制作海报或一页结果概览，将图表标题写成可判断的陈述。

**验收**：他人能理解并按预算复现，明确哪些部分依赖官方预训练，哪些是你的改动。

### 36｜完成最终复盘

按下一节完成所有关卡。只对未通过的部分安排补学，不需要把每份 slides 从头再读一遍。最终写一页个人总结：掌握了什么、仍欠缺什么、最关键三次错误、下一篇要精读的论文及理由。

## 11. “吃透”的验收：具体怎么考、哪里不过回哪里

### 11.1 统一评分办法

每个主题按四个维度分别打 0–2 分：**解释、推导/设计、实现/分析、证据与复现**。

- **0 分**：不能独立说明，或只复制结果。
- **1 分**：在提示下可以完成，但对形状、边界或实验条件解释不清。
- **2 分**：独立完成，能说明为什么、如何核验以及何时失效。

主干主题建议四维都达到 2 分；专题阅读可用算法设计、手算和实验方案分析代替完整大模型实现。不要用专题的低成本验收代替核心作业训练。以下是一套自学评分办法，并非 Stanford 官方评分标准。

### 11.2 五个阶段关卡

| 关卡 | 闭卷解释/推导 | 当场实现或分析 | 应有证据 | 不通过回到 |
|---|---|---|---|---|
| G1 分类与网络 | Softmax、链式法则、正则与数据划分 | 画两层网络并写梯度形状；定位一个广播错误 | A1 五题、梯度检查、小样本过拟合、验证曲线 | 02–10 |
| G2 CNN 与训练 | 卷积尺寸、归一化统计轴、Dropout 模式 | 手算 CNN 参数/输出；诊断 train/val 分离 | A2 前四题、归一化/Dropout 实验、框架训练记录 | 11–15 |
| G3 序列与注意力 | BPTT、teacher forcing、QKV、位置与 mask | 写出多头中间形状；说明采样流程 | A2 RNN、A3 caption/ViT、题内检查 | 16–19 |
| G4 表征与生成 | 对比/自蒸馏/配对监督、ELBO、DDPM 与 CFG | 画损失索引；推加噪与采样条件 | A3 后三题、表征对照、检索/分割与采样结果 | 20–25 |
| G5 全课与项目 | 根据任务选模型/指标；界定主张 | 设计 baseline、消融与泄漏检查 | 专题产出、报告、复现说明、失败分析 | 26–35 |

若某项依赖延后下载，例如 DAVIS，不将该实验打成已完成；可先通过理论部分，待需要时补运行。原题阈值看 Notebook，不为所有梯度、数据集和模型制定统一分数线。

### 11.3 15 道口试题：用检查要点判断回答是否完整

建议分三次做，每次 5 题；每题先讲 2–3 分钟，再追问一个反例。允许画图，不先翻资料。

| 题目 | 回答应覆盖的检查要点 |
|---|---|
| 1. kNN 无循环距离怎样算，内存会卡在哪？ | 平方距离展开、测试×训练矩阵、广播、分块思路 |
| 2. Softmax 为什么减最大值，初始损失为什么接近 log(C)？ | 平移不变性、数值稳定、近均匀概率与正则条件 |
| 3. 广播偏置在反向传播时怎么求梯度？ | 与参数相同形状、沿复制维度归约、分支贡献相加 |
| 4. 数值梯度不一致，就一定是解析梯度错吗？ | 步长/精度、不可导点、随机性、检查函数和正则系数 |
| 5. 训练好验证差，下一步怎么查？ | 先查划分/模式/预处理，再考虑过拟合、正则和分布差异 |
| 6. BN、LN、Dropout 的训练与推理有何差异？ | 统计轴、running state、随机掩码与缩放、eval/no_grad 不同 |
| 7. 卷积反向为什么必须累加重叠贡献？ | 参数共享、输入多路径、padding 与输出形状 |
| 8. RNN 的训练输入为什么错开一个 token？ | 自回归目标、teacher forcing、mask 与采样差异 |
| 9. Attention 为什么有缩放，causal mask 防什么？ | 点积尺度、softmax、未来信息泄漏、Q/K/V 轴 |
| 10. ViT 增加图像分辨率，会怎样影响成本？ | 固定 patch 下 token 数增加，常规全局注意力的二次项 |
| 11. SimCLR 的 projection head 和 encoder 为何区分？ | 训练损失空间与下游表示、增强、温度、评价协议 |
| 12. CLIP 与 DINO 的监督来源和目标有何不同？ | 图文配对、对比目标；师生 EMA、自蒸馏、无显式负样本 |
| 13. DDPM 怎样直接获得任意时刻的噪声图？ | alpha 累积、高斯闭式、时间索引、噪声预测目标 |
| 14. CFG 提高条件一致性就一定更好吗？ | 权重约定、两路预测、质量/多样性权衡、失败与证据 |
| 15. 项目提升两百分点，怎样证明结论可信？ | 相同协议、验证选参、测试隔离、重复/波动、消融与成本 |

只会背关键词记 1 分；能把关键词连接到自己的实现、图表和失败例再考虑 2 分。解释中发现矛盾应回查并修正日志。

### 11.4 训练异常排查顺序

| 现象 | 先检查 | 用什么最小实验区分原因 |
|---|---|---|
| loss 是 NaN/Inf | 输入和参数是否有限；log/exp、除零、学习率、dtype | 极小输入只跑一层，打印中间统计，先做数值稳定版本 |
| 梯度检查不通过 | 形状/归约轴、正则系数、cache、随机种子、不可导点 | float64 小张量，逐层查，与 naive/参考结果对照 |
| loss 不降 | 参数是否更新、清梯度/反传顺序、标签对齐、学习率 | 一小批数据反复训练，直接比较更新前后参数 |
| 小样本也记不住 | 基础实现、容量、正则、模式、数据和损失连接 | 去掉额外复杂性，用可控小模型做过拟合 |
| 训练好、验证差 | 数据泄漏/偏移、预处理、train/eval；再查过拟合 | 固定划分，检查同一输入在两模式差异，比较曲线 |
| RNN/Transformer 输出重复或错位 | 输入目标移位、mask、特殊 token、采样终止 | 手工构造极短序列，逐步打印 token 和预测 |
| 生成结果全噪声 | 时间索引、系数广播、checkpoint 匹配、数据归一化、采样模式 | 固定种子保存几个中间 t，对照模型目标和加载键 |
| 显存不足/特别慢 | batch、token/分辨率、是否保留计算图、DataLoader/设备 | 小批测峰值内存，区分数据读取、前向、反向开销 |

一次提出一个假设，用最小实验验证后再改下一处。记录排除了什么，而不是无顺序地同时修改学习率、结构和数据。

### 11.6 间隔复习与补学

- **任务后 24–48 小时**：不看资料画一遍数据流，写一个公式/形状和一个常见错误；忘记处只复查对应段落。

- **阶段结束**：执行 G1–G5 中当前关卡，整理错题表，标注对应步骤和补学行动。
- **项目结束**：选一个自己没有用过的方法，对比它为什么可能适合/不适合项目；检验迁移知识而非只熟悉作业答案。

论文用一页卡片复习：问题 → 原方法局限 → 本文关键变化 → 目标与形状 → 实验证据 → 局限 → 对应到自己的哪个函数。先读必要论文，再决定扩展，不把收藏 PDF 数量当作进度。
