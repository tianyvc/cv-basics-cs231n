# CS231n 2025：仓库导览、资料审计与完整学习路线

核查日期：2026-10-19（北京时间）。对象：Stanford CS231n Spring 2025。本文基于仓库逐目录扫描、Python 源码与 Notebook 单元检查、原始 ZIP 对照，以及当日可访问的官方课程主页和课表。下载的精确结果以 [下载清单](../resources/download_manifest.json) 和 [资料审计](资料审计.md) 为准。

## 1. 先认识这门课与这个仓库

CS231n 的核心是：把图像任务变成可优化的目标，理解神经网络的计算与梯度，再学会训练、诊断和评价视觉模型。分类、CNN、RNN、Transformer、自监督学习、生成模型构成主要实现路线；检测、视频、分布式训练、3D、视觉语言、机器人与 Human-Centered AI 扩展你的研究视野。

仓库的主干资料已经相当齐全，但它是**课程资料和官方练习模板的存档**，不是安装后就能跑出完整答案的项目。大量 `TODO`、`pass`、空白作答区是练习设计。14 本核心作业 Notebook 均没有已执行的代码单元；不能据此宣称已完成作业或模型已复现。原始 ZIP 和解压后已有同名文件逐字节比较一致，未发现已有解答被改写的情况。

官方主页的课程成绩构成为：三次作业合计 45%，期中 20%，项目 35%，另有参与加分。自学时也应保留项目与闭卷复习这两部分；只浏览幻灯片或只完成作业，都不足以覆盖课程目标。

学习材料之间的分工：

| 材料 | 最适合解决的问题 | 推荐用法 |
|---|---|---|
| `slides/2025/` | 本讲有哪些问题、模型和方法 | 先看结构，再在作业后回看 |
| `readings/notes/` | 基础公式、推导、训练细节 | 跟随第 2–6 讲精读，不必一口气读完 |
| `readings/handouts/` | 梯度为什么这样传播 | 第 4 讲与作业 1 同步手推 |
| `assignments/` | 能否把概念变成正确可运行的实现 | 以 Notebook 指示为入口，去 `.py` 完成实现 |
| `readings/papers/` | 方法为何提出、证据是否支持主张 | 实现相关模块后精读核心论文 |
| `resources/official/` | 官方课表、项目、环境与政策依据 | 定位资料、规划项目、核实历史要求 |
| `resources/blogs/` | 对难点建立直观图景 | 遇到疑问时读对应文章 |

| `tools/` | 如何复查、补下资料 | 使用下载脚本并检查清单 |

## 2. 每个文件夹具体做什么

### 2.1 根目录及隐藏目录

- `README.md`：原有逐讲索引和资料入口；本次补充了学习文档入口及勘误。README 中部分历史作业描述沿用宽泛标签，具体题目应以 Notebook 为准。
- `.gitignore`：排除环境、缓存、编译产物等；它不代表文件不存在，`build/`、`__pycache__/` 就是扫描到的实际例子。
- `.git/`：版本控制对象、引用、日志、hooks 等内部目录，属于 Git 元数据，不是学习内容；无需逐个阅读对象目录。
- `.agents/`、`.codex/`、`.aws/`：当前环境中的工具或配置挂载目录，初次扫描下未列出普通文件；不属于课程。无需为学 CS231n 配置云账号，也不在课程盘点中导出任何凭据。

### 2.2 `slides/`：讲义与讨论课

`slides/2025/` 是主学习线：第 1 讲分两份 PDF，第 2–17 讲各一份，共 18 份讲课 PDF。四份原有讨论课分别是：

| 文件 | 官网对应内容 | 学习时机 |
|---|---|---|
| `section_2.pdf` | Backprop Review | 学习反向传播、写作业 1 时 |
| `section_3.pdf` | Final Project Overview and Guidelines | 完成分类基础后，尽早选题 |
| `section_5.pdf` | RNNs & Transformers | 完成 RNN，进入 attention 时 |
| `section_6.pdf` | Midterm Review | 学完第 1–12 讲后自测 |
| `section_2_backprop.ipynb` | 官网链接的反向传播讨论课代码，本次补充 | 对照计算图做实验 |
| `section_4_pytorch.ipynb` | 官网链接的 PyTorch 讨论课代码，本次补充 | 作业 2 的 PyTorch 题前 |
| `section_5_rnn_transformers.ipynb` | 官网链接的序列模型讨论课代码，本次补充 | 第 7、8 讲配套 |

编号空缺不等于缺 PDF：Python 复习使用 `readings/notes/python-colab.ipynb`，PyTorch 复习在官网只链接 Colab。不能因为没有 `section_1.pdf` 或 `section_4.pdf` 就凭空寻找相同编号的幻灯片。

`slides/2024/` 是历史补充：`lecture_6_part_1.pdf`、`lecture_6_part_2.pdf`、`lecture_6_review.pdf` 提供 CNN 相关备用视角，`lecture_18.pdf` 提供旧版 Human-Centered AI 内容。优先学 2025 第 6 讲；2024 材料按需要对照。**2025 官网第 18 讲没有公开幻灯片链接，2024 文件不能标成 2025 原版。**

`slides/2021/` 的 `discussion_4_tensorflow.ipynb` 是 README 原先提到、实际缺失后补下的历史资料。它不在 2025 主线里。除非想了解 TensorFlow，不需要把它放进必修计划。

### 2.4 `readings/handouts/`：数学讲义

- `derivatives.pdf`：向量、矩阵求导与形状约定。重点不是背矩阵求导表，而是对每个中间变量标出维度。
- `linear-backprop.pdf`：线性层反向传播的具体例子。可以用它独立推导 `affine_backward`。
- `1998_Efficient_BackProp.pdf`：官网第 4 讲建议阅读的 LeCun 等人的 *Efficient BackProp*，本次补充。它与 LeNet 识别论文是不同文献。

### 2.5 `readings/papers/`：论文按主题阅读

原有 14 篇论文覆盖 LeNet、AlexNet、VGG、GoogLeNet、ResNet，R-CNN/Fast R-CNN/Faster R-CNN、YOLO、FCN、DETR，以及 Transformer、ViT、DINO。

补充的论文为 Batch Normalization、VAE、GAN、SimCLR、DDPM、CLIP、Classifier-Free Guidance。这些主要服务作业 2、3 和生成模型讲座。它们是为学习闭环补充的阅读，不应全部称为“官网指定必读”。文件名中的年份采用方法首次论文/预印本常见年份，可能与正式会议年份不同，例如 ViT 的 `2020` 对应预印本，正式发表于 ICLR 2021。

建议每篇写一页卡片：任务；之前的瓶颈；核心结构和目标函数；输入输出形状；关键实验与消融；局限；它与自己代码中哪一部分对应。第一遍只读摘要、图、方法主公式、实验结论；第二遍再推细节与补充材料。

## 3. 缺项究竟意味着什么

**按最新要求，大型或下载困难的资源已停止下载，残缺分片已清理。** 请配合阅读 [未下载资源与按需获取指南](未下载资源与按需获取指南.md)：它逐项列出用途、学习阶段、大小、官方下载入口、存放路径、使用方法及 Colab 省空间方案。学到需要实验的阶段再获取，前置数学和概念学习可立即开始。

本次将问题分为四种，避免把“学员需要完成的内容”误当资料损坏：

## 4. 推荐学习顺序：先形成实现闭环，再扩展研究视野

下面的顺序保留课程概念依赖，同时允许把高级专题安排在主干实现之后。每个阶段都应留下可检查的产物。

### 阶段 0：准备 Python、数学和实验环境

材料：`python-numpy-tutorial.md` → `python-colab.ipynb` → 必要时看 Jupyter 教程；结合 `derivatives.pdf` 补链式法则、矩阵乘法、期望与方差、条件概率、对数似然。

必须做到：能解释 `(N,D) @ (D,C)`；用广播算全体样本两两距离；理解 `axis`、`keepdims`、切片、浅拷贝；能把训练/验证/测试用途说清。写小函数并检查输出形状，不用先把全部微积分课补完。

产物：一页 NumPy 形状笔记、一个可启动的 Jupyter/Colab 环境、一段自写的有限差分函数。

### 阶段 1：图像分类与线性模型

顺序：第 1 讲概览 → 第 2 讲 → `classification.md`、`linear-classify.md` → A1 `knn.ipynb`、`softmax.ipynb` → 第 3 讲与 `optimization-1.md`。

关键问题：kNN 为什么预测慢；L1/L2 距离在像素空间有什么局限；线性决策边界表达不了什么；为什么要做数值稳定的 Softmax；正则项改变什么；为什么验证集不能充当训练数据；为什么调参不能反复看测试集。

产物：两层循环、单循环、无循环的距离实现对照；k 的交叉验证图；Softmax 的 naive/vectorized 结果对照与梯度检查；训练/验证曲线。

### 阶段 2：反向传播和全连接网络

顺序：第 4 讲 → `optimization-2.md` → 两份求导讲义 → `section_2.pdf` 与 Notebook → `neural-networks-1/2/3.md` → A1 `two_layer_net.ipynb` → `features.ipynb` → `FullyConnectedNets.ipynb`。再以 case-study 笔记复盘。

先在纸上推 `Y=XW+b`、ReLU、Softmax cross-entropy 的梯度，标出形状；随后实现、做有限差分，最后训练。理解 cache 保存什么和为什么要保存。检查优化器的状态变量，区分参数、梯度、动量和二阶矩。

产物：完整 A1、各层梯度检查、小样本过拟合实验、学习率/正则化搜索记录。能口头从一张图像讲到分数、损失、反向传播和参数更新，才进入下一阶段。

### 阶段 3：CNN 与训练技巧

顺序：第 5、6 讲 → `convolutional-networks.md` → A2 BN/LN → Dropout → 卷积/池化 → PyTorch 讨论课 → `PyTorch.ipynb`。论文顺序推荐 AlexNet → VGG → ResNet → BN；GoogLeNet、LeNet 用于补历史与结构比较。

重点：padding/stride/kernel 对输出大小和感受野的影响；参数共享如何减少参数；BN/LN/GroupNorm 沿哪些轴统计；训练与推理为何不同；Dropout 的缩放；优化器与学习率调度；手写梯度和 autograd 的对应关系。

产物：A2 前四题、卷积形状推导、朴素/快速实现对照、CIFAR 训练曲线、至少一个受控消融。只改变一个因素，例如相同架构加/不加 BN，而不是把所有改进混在一起。

此时开始读 `section_3.pdf` 和项目说明，确定数据、基线和指标。不要拖到所有高级内容看完才选题。

### 阶段 4：RNN、Attention、Transformer、ViT

顺序：第 7 讲 → LSTM 文章 → A2 `RNN_Captioning_pytorch.ipynb` → 第 8 讲 → Illustrated Transformer → `section_5.pdf`/Notebook → Transformer 原论文 → A3 `Transformer_Captioning.ipynb` → ViT 论文。

需要画出 RNN 的时间展开图，解释 teacher forcing、token embedding、padding mask、因果 mask、训练时与采样时的区别。对 attention 写清 `Q/K/V`、每个 head 的维度、缩放项和 softmax 的轴。对 ViT 写清 patch 展平、位置编码、CLS token 与输出分类头。

产物：A2 第五题与 A3 第一题；同一批图像的 RNN/Transformer caption 定性比较；ViT 小实验。Notebook 中 ViT 给出了两轮 CIFAR-10 后准确率大于 0.45 的题内目标，按原题条件核验，勿把它推广成所有配置的标准。

### 阶段 5：自监督、CLIP 与 DINO

顺序：第 12 讲 → 自监督文章 → SimCLR 论文 → A3 `Self_Supervised_Learning.ipynb` → 第 16 讲 → CLIP 与 DINO 论文 → `CLIP_DINO.ipynb`。

理解：增强如何定义任务；正负样本与温度；encoder 和 projection head 区别；线性探测与全量微调区别；CLIP 用自然语言配对监督，不能简单等同于完全没有监督；DINO 是无显式负样本的自蒸馏，不应仅因为作业引言简化表述就把它叫成普通对比损失。

产物：对比损失向量化实现、预训练/随机初始化对照、零样本类别提示词实验、检索案例、DINO attention/PCA/分割可视化。保留训练帧与测试帧的区分，说明实验是否反映跨视频泛化。

### 阶段 6：生成模型与扩散

顺序：第 13 讲 → ELBO 文章 → VAE/GAN 原论文选读 → 第 14 讲 → DDPM 论文 → A3 `DDPM.ipynb` → Classifier-Free Guidance 论文。

必须能区分概率密度建模、变分下界、对抗学习和扩散去噪目标。对 DDPM 先推 `q(x_t|x_0)`，再实现加噪、噪声预测损失、反向采样和 U-Net；明确 beta、alpha、累积 alpha 与时间索引的关系。理解条件与无条件预测怎样组合，采样为何要多步。

产物：加噪随时间演变图、不同 guidance 强度的采样对比、采样/训练模式说明。作业提供预训练检查点，不要求从头跑完所有训练步；先通过题中检查并能正确采样，再决定是否扩展训练。

### 阶段 7：补齐视觉研究版图

### 阶段 8：完成一个有证据的独立项目

阅读 `resources/official/project.html` 和 `slides/2025/section_3.pdf`。项目占课程 35%，官方要求包含 proposal、milestone、final report 和 poster/code。自学可沿用相同阶段。

建议从“小数据集上的迁移学习/自监督特征比较”开始：先做随机初始化 CNN 或 frozen feature + linear head 的基线，再比较监督预训练、CLIP、DINO 之一；固定划分，报告分类准确率、宏平均 F1、训练时间和失败案例。也可选小规模检测/分割、captioning 或扩散研究，但一次只提出一个主要问题。

5. 6–8 页 final report：Introduction、Related Work、Data、Methods、Experiments、Conclusion、参考文献；引用代码和数据来源。

项目报告索引可用来理解题目和写作尺度，不需要下载全部历年项目。建议先看标题和摘要，围绕自己的选题再精读。

## 6. 本地运行与常见陷阱

### 6.1 优先选择 Colab，或为本地创建独立环境

官方 Notebook 首单元挂载 Google Drive，`FOLDERNAME` 使用课程示例值。无论使用 Colab 还是本地，都要让路径指向实际包含 Notebook 与 `cs231n/` 的内层目录。不要在本地直接执行 `from google.colab import drive`。

本地示例：

```bash
cd /home/owl/cs231n-2025
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install numpy scipy matplotlib pillow imageio h5py cython jupyterlab
# PyTorch 与 torchvision 根据操作系统、Python、CUDA 在其官网选择匹配安装命令
cd assignments/assignment1/assignment1
jupyter lab
```

这是建议的基础环境，不是已锁定、已端到端验证的 requirements。A3 还用到 pandas、tqdm、joblib、einops、scikit-learn、thop、ftfy、regex、CLIP、tensorflow/tensorflow-datasets、OpenCV、decord 等；以实际 imports 和相关 Notebook 单元为准。GPU 环境要保证 torch 与 torchvision 匹配。A3 的旧 `requirements.txt` 固定了 NumPy 1.19.5 等历史版本，且未完整列出 torch 等当前所需包，不宜直接当成现代 Python 的一键安装方案。A2 说明虽提 requirements，本地原包实际上没有该文件，不应伪造一份称为官方要求。

在本地跳过 Drive 单元后，工作目录应为当前作业根；可以先运行：

```python
from pathlib import Path
assert Path('cs231n').is_dir()
import cs231n
print(cs231n.__file__)
```

切换作业时重启内核，避免导入前一个作业的 `cs231n`。Cython 编译按卷积 Notebook 的原指示操作；本地通常从 A2 的 `cs231n/` 下运行 `python setup.py build_ext --inplace`，如果编译器、NumPy/Cython 或 Python 版本变化，需要按报错调整，而不是盲目信任原包 `.so`。

### 6.2 数据与模型

- CIFAR-10：A1/A2 的 NumPy 工具预期 `cs231n/datasets/cifar-10-batches-py/`；A3 的 torchvision 部分默认 `data/`，缓存布局不同。已有 Python batch 目录不一定能阻止 `torchvision` 检查归档并重新下载。
- COCO：这里使用课程准备的图像特征、词表、caption 等，不是完整 COCO 原始图像集。`coco_utils.py` 默认以相对路径寻找 `cs231n/datasets/coco_captioning/`。
- ImageNet：`imagenet_val_25.npz` 是很小的示例，不是完整 ImageNet。核心作业不是都需要它。
- SimCLR：`pretrained_model/pretrained_simclr_model.pth` 是下载资源；`trained_simclr_model.pth` 是继续训练后的输出。
- DDPM：`emoji_data.npz`、`text_embeddings.pt` 放在 A3 `cs231n/datasets/`；Notebook 的 `results_folder` 本地应改为 `cs231n/exp/pretrained`，使 `trainer.load(70000)` 能找到检查点。自学先用提供的权重，不必直接启动 50000 步训练。
- CLIP / DINO / DAVIS：首次运行仍可能联网，CLIP 下载到自身 cache，DINO 使用 `torch.hub`，DAVIS 由 `tensorflow_datasets` 处理。未预置这些库管理的全部资源，详情见审计。

原始下载脚本大量使用 HTTP、`wget` 并依赖当前目录。更可靠的做法是使用本次脚本下载、按审计结果检查，不要重复下整份 COCO，也不要把下载失败的 HTML 改后缀充当权重。

### 6.3 版本变化需要留意的具体点

PyTorch 新版本的 `torch.load` 默认参数与旧环境不同；如果 sanity key 或 checkpoint 加载报 `weights_only` 相关错误，应先确认下载来源及文件完整性，再按该版本文档选择加载方式。梯度检查通常用较高精度，并避开 ReLU 不可导点；训练则使用题目要求的 dtype。DataLoader 的 16 workers 是模板参数，本地资源不足可适当减少。A3 部分调用写死 `device='cuda'`，仅有 CPU 时需要调整调用，完整训练速度仍可能很慢。

`collect_submission` 安装 TeX/Pandoc 是为了提交 PDF，自学阶段不必为做第一道题就安装完整 TeX。你应定期保存 Notebook、实现文件和实验记录；最终复现时重启内核按顺序运行，避免隐藏状态让结果无法重现。

## 7. 如何判断自己已经吃透

逐项检查，而不以“看完视频”计数：

- [ ] 能从头推并实现 affine/ReLU/Softmax、卷积、池化与常用归一化的关键梯度。
- [ ] 能解释训练/验证/测试、数据泄漏、过拟合、正则化，并设计公平对照。
- [ ] 完成 14 本核心作业 Notebook 的代码与文字问答，保存主要检查和训练结果。
- [ ] 遇到 loss 不降、梯度异常、验证变差时，能用小样本过拟合、统计和梯度检查定位原因。
- [ ] 能用 NumPy 手写训练流程，也能用 PyTorch 的 autograd、Module、DataLoader 实现同类模型。
- [ ] 能画出 CNN、RNN、Transformer、ViT 的数据流，明确关键张量形状和时间/显存成本。
- [ ] 能区分监督、对比、自蒸馏、图文配对监督，正确评价表征与下游任务。

- [ ] 能说明检测/分割/视频/3D/机器人与分类任务的不同，并选择合适指标。
- [ ] 至少完成一个有 baseline、消融、错误分析、复现说明和局限讨论的独立项目。
