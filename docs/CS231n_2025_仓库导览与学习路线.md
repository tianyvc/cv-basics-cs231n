## 1. 先认识这门课与这个仓库

CS231n 的核心是：把图像任务变成可优化的目标，理解神经网络的计算与梯度，再学会训练、诊断和评价视觉模型。分类、CNN、RNN、Transformer、自监督学习、生成模型构成主要实现路线；检测、视频、分布式训练、3D、视觉语言、机器人与 Human-Centered AI 扩展你的研究视野。

仓库的主干资料已经相当齐全，但它是**课程资料和官方练习模板的存档**，不是安装后就能跑出完整答案的项目。大量 `TODO`、`pass`、空白作答区是练习设计。2026-10-19 扫描时，14 本核心作业 Notebook 均没有已执行的代码单元；不能据此宣称已完成作业或模型已复现。首次核查时，原始 ZIP 与解压文件相同；2026-10-28 已在解压目录进行本地运行改造，原 ZIP 仍保留上游模板。

官方主页的课程成绩构成为：三次作业合计 45%，期中 20%，项目 35%，另有参与加分。自学时也应保留项目与闭卷复习这两部分；只浏览幻灯片或只完成作业，都不足以覆盖课程目标。

## 2. 每个文件夹具体做什么

### 2.1 根目录及隐藏目录

- `README.md`：原有逐讲索引和资料入口；本次补充了学习文档入口及勘误。README 中部分历史作业描述沿用宽泛标签，具体题目应以 Notebook 为准。
- `.gitignore`：排除环境、缓存、编译产物等；它不代表文件不存在，`build/`、`__pycache__/` 就是扫描到的实际例子。
- `.git/`：版本控制对象、引用、日志、hooks 等内部目录，属于 Git 元数据，不是学习内容；无需逐个阅读对象目录。
- `.agents/`、`.codex/`、`.aws/`：当前环境中的工具或配置挂载目录，初次扫描下未列出普通文件；不属于课程。无需为学 CS231n 配置云账号，也不在课程盘点中导出任何凭据。

### 2.2 `slides/`：讲义与讨论课

`slides/2025/` 是主学习线：第 1 讲分两份 PDF，第 2–17 讲各一份，共 18 份讲课 PDF。四份原有讨论课分别是：

| 文件 | 官网对应内容 | 学习时机 |
|---|---|---|
| `section_2.pdf` | Backprop Review | 学习反向传播、写作业 1 时 |
| `section_3.pdf` | Final Project Overview and Guidelines | 完成分类基础后，尽早选题 |
| `section_5.pdf` | RNNs & Transformers | 完成 RNN，进入 attention 时 |
| `section_6.pdf` | Midterm Review | 学完第 1–12 讲后自测 |
| `section_2_backprop.ipynb` | 官网链接的反向传播讨论课代码，本次补充 | 对照计算图做实验 |
| `section_4_pytorch.ipynb` | 官网链接的 PyTorch 讨论课代码，本次补充 | 作业 2 的 PyTorch 题前 |
| `section_5_rnn_transformers.ipynb` | 官网链接的序列模型讨论课代码，本次补充 | 第 7、8 讲配套 |

编号空缺不等于缺 PDF：Python 复习使用 `readings/notes/python-colab.ipynb`，PyTorch 复习在官网只链接 Colab。不能因为没有 `section_1.pdf` 或 `section_4.pdf` 就凭空寻找相同编号的幻灯片。

`slides/2024/` 是历史补充：`lecture_6_part_1.pdf`、`lecture_6_part_2.pdf`、`lecture_6_review.pdf` 提供 CNN 相关备用视角，`lecture_18.pdf` 提供旧版 Human-Centered AI 内容。优先学 2025 第 6 讲；2024 材料按需要对照。**2025 官网第 18 讲没有公开幻灯片链接，2024 文件不能标成 2025 原版。**

`slides/2021/` 的 `discussion_4_tensorflow.ipynb` 是 README 原先提到、实际缺失后补下的历史资料。它不在 2025 主线里。除非想了解 TensorFlow，不需要把它放进必修计划。

### 2.4 `readings/handouts/`：数学讲义

- `derivatives.pdf`：向量、矩阵求导与形状约定。重点不是背矩阵求导表，而是对每个中间变量标出维度。
- `linear-backprop.pdf`：线性层反向传播的具体例子。可以用它独立推导 `affine_backward`。
- `1998_Efficient_BackProp.pdf`：官网第 4 讲建议阅读的 LeCun 等人的 *Efficient BackProp*，本次补充。它与 LeNet 识别论文是不同文献。

### 2.5 `readings/papers/`：论文按主题阅读

原有 14 篇论文覆盖 LeNet、AlexNet、VGG、GoogLeNet、ResNet，R-CNN/Fast R-CNN/Faster R-CNN、YOLO、FCN、DETR，以及 Transformer、ViT、DINO。

本次已补充 Batch Normalization、VAE、GAN、Classifier-Free Guidance；SimCLR、DDPM、CLIP 因下载困难而延后，可在线阅读。这些主要服务作业 2、3 和生成模型讲座。它们是为学习闭环补充的阅读，不应全部称为“官网指定必读”。文件名中的年份采用方法首次论文/预印本常见年份，可能与正式会议年份不同，例如 ViT 的 `2020` 对应预印本，正式发表于 ICLR 2021。

论文精读顺序、卡片模板和知识验收见新指南；精确本地状态见资料审计。

## 3. 缺项究竟意味着什么

## 6. 本地运行与常见陷阱

### 6.1 本地初始化已经改好

三次作业的首单元已改为调用 `tools/local_runtime.py`：自动定位仓库和内层作业根，不导入 `google.colab`，不自动下载/安装。切换作业需要重启内核，避免同名 `cs231n` 包串用。原始 ZIP 保留上游版本；重新解压会覆盖本地改造和你的作答，不要这样更新。

现有机器的 conda `cs231n` 是 Python 3.10，可直接激活；新环境配置在 `environments/cs231n.yml`。基础、PyTorch、A3 和编译器的分阶段说明见 [本地说明第 2 节](本地实验与存储管理.md#2-conda-与依赖按阶段准备)。旧 A3 requirements 不作为当前安装方案。

### 6.2 数据只保留一份

在仓库根执行 `python tools/local_resources.py status` 查看；进入需要数据的阶段才用 `fetch cifar10`、`fetch coco` 等精确命令。CIFAR/COCO 在根 `datasets/` 共享，torchvision 使用同一目录且禁止自动重复下载。权重在 `models/`，库缓存在 `cache/`，你的成果在各作业 `results/`。

默认下载成功并验证解压后删除完整归档；不自动删除数据。`clean <资源名>` 只预览，加 `--yes` 才删除。各资源的下载时点、复用与最后使用时间见新指南每步，以及 [本地生命周期表](本地实验与存储管理.md#4-每个资源何时下载何时用完)。

### 6.3 后续题的本机差异

A2 的 Cython 扩展要匹配本机 Python/NumPy，使用 Notebook 的显式构建开关。A3 已移除无用 TensorFlow 私有导入、写死云盘路径和常用 CUDA 调用；可按设备运行，CPU 完整训练仍可能较慢。多进程 DataLoader 在本地 Notebook 默认设为 0。

CLIP/DINO/DAVIS 首次获取需要显式打开对应下载开关。提交导出默认关闭，使用轻量 Python 打包与 HTML，不执行系统安装。以上是运行基础设施改造，不代表核心 TODO 和训练实验已经完成。
