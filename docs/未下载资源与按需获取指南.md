## 1. 哪些学习阶段需要再下载什么

| 学习阶段 | 需要按需获取的资源 | 未下载的影响 | 最省空间的办法 |
|---|---|---|---|
| NumPy/数学、讲义阅读 | 无新增大型资源 | 可以直接开始 | 使用本地笔记、插图、讨论课 |
| A1 kNN/Softmax/全连接 | CIFAR-10，约 162.6 MiB 压缩包 | 仍能写推导与跑小张量检查，不能完整训练/评价 CIFAR | 第 05 步获取一次，后续作业复用 |
| A2 BN/Dropout/CNN/PyTorch | 同一份 CIFAR-10 | 完整数据实验依赖它 | 复用 A1 数据，不重新存三份 |
| A2 RNN、A3 Transformer captioning | 课程 COCO captioning，约 987.3 MiB | 缺图像特征、caption、词表，不能完成数据部分 | 在 datasets/ 解压一份，共享给两次作业 |
| A3 ViT、SimCLR | CIFAR-10；SimCLR 预训练权重约 94.2 MiB | ViT 数据训练、SimCLR 预训练比较尚不能直接运行 | 分阶段获取；先做小张量损失检查 |
| A3 DDPM | Emoji 约 28.6 MiB、检查点约 142.7 MiB；CLIP 模型另下 | 加噪公式可学，完整生成缺数据/权重 | 使用预训练检查点，避免从头长训练 |
| A3 CLIP/DINO | CLIP/DINO 权重、hub 源码；COCO；DAVIS | 零样本、检索和分割需额外获取 | CLIP 与 DINO 依次加载，DAVIS 最后再下 |
| 论文精读 | SimCLR、DDPM、CLIP PDF；RNN 书章 | 不影响读讲义，原论文细节需在线阅读 | 使用浏览器在线阅读，按需另存 |
| 2025 视频、评分/考试 | 校内权限 | 公开仓库无法提供完整课程平台体验 | 走合法课程账号；用公开往年视频辅助概念 |

学习指南的阶段 0–3 可先开始，不必等待高级模型权重。只想理解原理时，下载大数据并不是前置条件；要声称完成训练和达到题目指标时则必须使用相应数据与评价条件。

## 2. CIFAR-10：最早需要的数据

- 用途：A1 图像分类、A2 网络训练、A3 ViT 和 SimCLR。10 类 32×32 彩图，标准 50000 张训练图、10000 张测试图；作业还会从训练部分划验证集。
- 获取：[数据集说明](https://www.cs.toronto.edu/~kriz/cifar.html)、[Python 版压缩包](https://www.cs.toronto.edu/~kriz/cifar-10-python.tar.gz)。约 162.6 MiB，解压约需更多同量级空间。
- 本地存放：`datasets/cifar-10-python.tar.gz`；准备脚本解压到 `datasets/cifar-10-batches-py/`，在各作业的 `cs231n/datasets/` 创建相对链接。

未来下载示例，从仓库根执行：

```bash
curl -L --fail --retry 3 -C - https://www.cs.toronto.edu/~kriz/cifar-10-python.tar.gz -o datasets/cifar-10-python.tar.gz
python tools/prepare_datasets.py
```

不要解压未完成的归档。当前 torchvision 使用 `CIFAR10(root=str(DATA_DIR), download=False)`，与 NumPy 共享同一解压目录。手动准备已有归档后运行 `python tools/local_resources.py prepare`。推荐直接使用 `fetch cifar10`，它默认验证、解压并移除归档。

## 3. 课程版 COCO captioning：最大的一项，建议云端用

- 用途：A2 RNN captioning、A3 Transformer captioning，以及 CLIP 题中的部分输入。包含课程准备的图像特征、caption、词表等，并非完整 COCO 数据集。
- 地址：[课程版 COCO](https://cs231n.stanford.edu/coco_captioning.zip)，约 987.3 MiB 压缩，解压另占空间；它是本次停止下载的主要对象。
- 本地路径：`datasets/coco_captioning.zip` → 解压为 `datasets/coco_captioning/`，用准备脚本链接到 A2/A3。

```bash
curl -L --fail --retry 3 -C - https://cs231n.stanford.edu/coco_captioning.zip -o datasets/coco_captioning.zip
python tools/prepare_datasets.py
```

本地推荐 `python tools/local_resources.py fetch coco`：验证解压后删除归档并布置共享链接。课程 `coco_utils.py` 默认路径无需手改，A2/A3 均使用共享目录。原下载 shell 入口也已改为调用共享工具，不额外下载第二份。

`load_coco_data(max_train=...)` 只缩减载入训练样本，不会把服务器归档下载大小缩小。不必为本题额外下载整个 COCO 2014/2017 图像集。

## 4. SimCLR 预训练权重

- 用途：A3 `Self_Supervised_Learning.ipynb` 用预训练 encoder 初始化，再进行短训练与下游分类对照。可避免从头进行原 Notebook 所述长时间预训练。
- 地址：[2025 官方存储](https://cs231n.stanford.edu/2025/storage/a3/pretrained_simclr_model.pth)，约 94.2 MiB；Notebook 原首选地址为 `http://downloads.cs.stanford.edu/downloads/cs231n/pretrained_simclr_model.pth`。
- 路径：`models/simclr/pretrained_simclr_model.pth`。

在仓库根执行 `python tools/local_resources.py fetch simclr`。Notebook 的预训练读取会定位到共享模型目录；你训练出的结果保存在 A3 `results/trained_simclr_model.pth`。

按 Notebook 读取 `model.load_state_dict(torch.load(...), strict=False)`。`trained_simclr_model.pth` 是你继续训练产生的结果，未提供不属于仓库缺项。可以先完成 augmentation 和 contrastive loss 小测试，学到预训练比较时再下载。

## 5. DDPM：Emoji、文本 embedding、预训练检查点

| 文件 | 状态/大小 | 作用 | 预期路径（相对 A3 根） |
|---|---|---|---|
| `emoji_data.npz` | 未下载，约 28.6 MiB | emoji 图片和文本条件 | 根 `datasets/emoji_data.npz` |
| `text_embeddings.pt` | 已下载，约 3.5 MiB | 预先计算的文本向量 | `cs231n/datasets/text_embeddings.pt` |
| `model-70000.pt` | 未下载，约 142.7 MiB | 第 70000 步 DDPM 检查点 | 根 `models/ddpm/model-70000.pt` |

来源：[Emoji](https://cs231n.stanford.edu/2025/storage/a3/emoji_data.npz)、[文本 embedding](https://cs231n.stanford.edu/2025/storage/a3/text_embeddings.pt)、[DDPM 检查点](https://cs231n.stanford.edu/2025/storage/a3/model-70000.pt)。

本地改造后 `EmojiDataset` 只检查已有文件，不会自动下载。进入完整采样时，在根目录分别执行 `python tools/local_resources.py fetch emoji` 与 `python tools/local_resources.py fetch ddpm`。Notebook 的 `trainer.load` 使用该共享检查点，自己的训练写到 A3 `results/ddpm/`。文本 embedding 已在作业内提供，不必重复获取。

即使不训练，也要完成自己的 U-Net 和 diffusion TODO，才能正确使用检查点。作业没有要求从头训练 50000 步；想省资源，先做公式推导、shape 检查、前向加噪与损失测试，最后按需下载检查点做采样。

代码中的 `paraphrases_dict.pkl` 和 `text_embeddings_augs.pt` 属于可选文本增强分支，默认 `load_augs=False`，当前主线不要求它们，也没有把它们当作必须补下的资源。

## 6. CLIP、DINO 与 DAVIS：由库管理的下载

### CLIP ViT-B/32

用途：A3 零样本分类、图文检索、DDPM 文本条件编码。入口为 [OpenAI CLIP 官方仓库](https://github.com/openai/CLIP)。在相应环境安装 Notebook 指定的库后：

```python
import clip
# 当前 Notebook 已提供受控加载器：显式允许首次下载，然后复用 cache/clip。
from local_runtime import load_clip
model, preprocess = load_clip('cuda', allow_download=True)
```

没有 GPU 时将 device 改成 `'cpu'`；模型仍需空间和内存。CLIP ViT-B/32 权重通常为数百 MB，以运行时实际版本为准；官方库源码中的 `_MODELS` 维护精确下载 URL 和校验信息，本次未下载且未独立测量大小。`download_root` 可以指定临时目录，上游默认通常是 `~/.cache/clip/`，本地 Notebook 已固定改用仓库 `cache/clip/`。

本次未把整个 CLIP 项目或权重存进课程仓库；已经下载的是 CLIP 原理图，而不是可执行模型。

### DINO ViT-S/8

用途：A3 attention map、patch feature PCA、视频分割。入口：[facebookresearch/dino](https://github.com/facebookresearch/dino)。Notebook 原调用：

```python
import torch
from local_runtime import load_dino
dino_model = load_dino(allow_download=True)  # 明确首次下载；缓存齐全后可设 False
```

该调用会获取 hub 代码和官方权重；ViT-S/8 约 2200 万参数，检查点通常为几十到约百 MB，精确大小由上游文件决定，本次未下载。上游默认常见缓存为 `~/.cache/torch/hub/`；本地首单元和加载器已改用仓库 `cache/torch/hub/` 与其 `checkpoints/`。离线使用需要同时准备模型定义和兼容权重，单独另存论文 PDF 没有帮助。

### DAVIS 视频分割数据

用途：`CLIP_DINO.ipynb` 的最后一部分，使用单帧标注训练轻量 patch 分类器，再评价同视频其他帧。入口：[DAVIS 项目](https://davischallenge.org/)、[TensorFlow Datasets DAVIS](https://www.tensorflow.org/datasets/catalog/davis)。

本仓库本地 `DavisDataset` 调用 TFDS 时接收 `data_dir` 和 `download=False`，默认不联网；Notebook 显式开关可允许首次获取。数据准备过程可能涉及完整源归档与 TFDS 转换缓存，即使选择 validation 也不代表只下载一个视频。可能占 GB 量级，本次未测量也未下载。

本地数据目录固定为 `cache/tfds/`。只在进入最后分割实验时开启 `ALLOW_DAVIS_DOWNLOAD`；用完后 `python tools/local_resources.py clean davis` 先预览，确认后加 `--yes`。原题指定 sample 和帧用于对照评价，换视频后不能声称原题指标等价。

## 9. 本地下载和清理入口

首次盘点清单的 `ok/deferred` 记录保留用于追溯；现在实际是否可用请运行 `python tools/local_resources.py status`。数据和权重不再使用旧阅读材料下载器的 `--data` 路径。

- 获取一个资源：`python tools/local_resources.py fetch cifar10`（其他名字见本地说明）。
- 已有归档离线准备：`python tools/local_resources.py prepare`。
- 预览清理：`python tools/local_resources.py clean cifar10`。
- 确认删除：同一命令追加 `--yes`；仅归档追加 `--archives-only`。
- 首次模型/TFDS 自动加载由 Notebook 的显式开关控制，默认 False。

默认验证解压后删除归档，复用一份共享数据；原始代码/Notebook、学习记录和你训练的结果不由资源工具批量删除。参照 [本地生命周期表](本地实验与存储管理.md#4-每个资源何时下载何时用完) 确定最后使用步骤再清理。
