## 5. 怎么清理：先看清单，再明确删除

查看占用：

```bash
python tools/local_resources.py status
```

资源用完后，先预览。以下示例都不会立刻删除：

```bash
python tools/local_resources.py clean cifar10
python tools/local_resources.py clean coco
python tools/local_resources.py clean simclr
python tools/local_resources.py clean clip
python tools/local_resources.py clean dino
python tools/local_resources.py clean davis
python tools/local_resources.py clean emoji
python tools/local_resources.py clean ddpm
```

确认后在同一命令末尾加 `--yes`。例如第 21 步确实不再需要 CIFAR：

```bash
python tools/local_resources.py clean cifar10 --yes
```

这会删除共享数据、该资源的残留归档/分片和指向它的作业链接；**不会删除你自己在作业目录放的真实数据文件夹**，也不处理结果目录。清理脚本只接受固定资源名，遇到目标被重定向到仓库外部时拒绝删除。删除后再用它需重新 fetch。

只删手动留下的完整/残缺归档而保留解压数据：

```bash
python tools/local_resources.py clean cifar10 --archives-only
python tools/local_resources.py clean cifar10 --archives-only --yes
```

COCO 同理。默认 `fetch` 解压校验成功就删除完整归档，因此一般无需额外处理。网络中断时留下 `.part` 以便续传，放弃续传可用对应 clean 命令清理。不要对整个 `datasets/` 或 `assignments/` 直接 `rm -rf`。

### 结果和环境缓存怎么处理

- 训练产生的 SimCLR 最佳权重在 A3 `results/trained_simclr_model.pth`；DDPM 自己训练的文件在 A3 `results/ddpm/`；DINO 视频在 A3 `results/dino_res.mp4`。这些是你的成果，资源清理工具不自动删除。
- 完成实验后保留文字答案、关键图、配置、必要最佳权重；先另存记录，再手动移走不再需要的中间检查点和重复视频。不要因为改运行路径就把自己的旧文件夹删掉。
- 提交导出默认关闭。需要时打开 `collect_submission.ipynb` 的 `EXPORT_RESULTS=True`；Python 工具仅打包源码/Notebook，HTML 可浏览器另存 PDF，不装 TeX，不打包数据/权重。
- conda 环境与 pip/conda 缓存通常在仓库外，`status` 不包含它们。必要时 `python -m pip cache info`、`conda clean --all --dry-run` 先查看，确认后自行清理包缓存。保留正在用的 `cs231n` 环境。
- 课程原始 ZIP 合计不大，建议作为起始模板保留；它不包含你的最新答案，不能用它“恢复”学习成果。
